# XAUUSD AI Trading Robot
An AI-powered trading bot for XAUUSD using ML, RL, XGBoost, and MT5 integration.

## Setup
1. Install dependencies: `pip install -r requirements.txt`
2. Update `config.py` with MT5 credentials.
3. Place historical data in `data/historical_xauusd.csv`.

## Running
Run `src/main.py` to start the bot.
